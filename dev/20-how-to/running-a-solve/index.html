Running a Solve

Before running a solve, initialize the library with init:

init(threads = true, stats = true, plots = false, int_type = Int64)

Once a mesh is parsed and precomputed (see Parsing a Mesh and Precomputing Geometry) and the release area is set up (see Defining a Release Area), collect the model parameters and solver settings into a Solution:

solution = Solution(
    alpha = 0.5,
    zeta = 1.25,
    rho = 1500.0,
    alpha_p = 0.5,
    alpha_u = 0.5,
    alpha_h = 0.5,
    p_MAX_RESIDUAL = 1e-4,
    h_MAX_RESIDUAL = 5e-1,
    u_MAX_RESIDUAL = 5e-1,
    MAX_ITERS = 150,
    MIN_ITERS = 100,
    h_clip = 0.0,
    h_min = 1e-3,
    Cells = Cells,
    location = "./solution",
    points = points,
    faces = faces,
)

Build a Solver from it, then run solve over the desired time span:

solver = Solver(solution)
time_steps, sol = solve(solver, (0.0, 30.0), saveat = 0.2, Cₘ = 0.9)

saveat sets the uniform interval at which the (adaptively time-stepped) solution is saved, and Cₘ caps the Courant number used to control step sizes.

Selecting explicit time integration

By default, GlissADe uses an implicit coupled solver (implicit = true). To use explicit time integration instead, pass implicit = false to init along with your choice of explicit_method:

init(threads = true, stats = true, implicit = false, explicit_method = :rk4)

Available explicit methods include:

  • :rk4 - Classical 4th-order Runge-Kutta (default). Recommended for general high-fidelity solves.
  • :rk45 - Adaptive 5(4) Dormand-Prince method with local error control.
  • :ssprk3 - 3rd-order Strong Stability Preserving Runge-Kutta. Great for flows with sharp fronts.
  • :rk2 - 2nd-order Runge-Kutta / Heun's method.
  • :euler - 1st-order Forward Euler method.

You can also specify explicit_method when constructing a Solution:

solution = Solution(
    alpha = 0.5,
    zeta = 1.25,
    rho = 1500.0,
    Cells = Cells,
    location = "./solution",
    points = points,
    faces = faces,
    explicit_method = :rk4,
)

See How does the library work? for how the solution process handles pressure, momentum, and thickness, and Getting Started for how to supply a custom basal_stress rheology model.
